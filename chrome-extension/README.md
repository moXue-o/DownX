# DownX Chrome 扩展

把浏览器里的下载交给本地 [DownX](../README.md)（多线程分段下载管理器）。

## 功能

- **右键菜单**：在链接 / 图片 / 音视频上右键 →「用 DownX 下载」；页面空白处右键 →「用 DownX 下载当前页」。
- **拦截浏览器下载**（**默认开启**）：浏览器一开始下载就取消它、转交给 DownX。可在选项页关掉。
- **Popup**：查看任务进度（进度条 / 速度 / 大小），支持 添加 / 暂停 / 继续 / 重试 / 删除。
- **角标**：图标角标显示进行中的任务数（`!` = 没连上 DownX）。
- **选项页**：端口、拦截开关，并可直接读写 DownX 的默认目录 / 代理 / 并发等设置。

> 把下载交给 DownX（**拦截**或右键菜单）时会弹一条通知；连不上 DownX 也会提示。拦截只作用于"新发起、正在下载、http(s)"的条目，且同一 URL 只接管一次（防循环），绝不批量操作下载列表。

## 安装（开发者模式）

1. 先启动 DownX 后台：运行一次 `downx.exe`（它会自动拉起后台服务，固定监听 `127.0.0.1:8787`）。
2. Chrome 打开 `chrome://extensions` → 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `chrome-extension/`。

## 说明

- 扩展通过本地 HTTP 接口与后台通信（`GET /ping`、`GET /state`、`POST /add`、`POST /pause|cancel|retry|remove`、`GET/POST /settings`）。
- 服务端口默认 `8787`；若被占用会退回随机端口——此时请在扩展选项页里改成实际端口（见 `%LOCALAPPDATA%\DownX\daemon.json`）。
- 扩展只需要 `http://127.0.0.1/*` 的主机权限，不联网任何外部地址。
